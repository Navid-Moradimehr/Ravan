# Purpose

Explain Ravan pages, historian navigation, Kafka UI, Grafana, Prometheus,
AI Reporting, replay, datasets, and world-model data preparation.

# Rules

- Prefer live platform read tools when answering current-state questions.
- Distinguish observed state, documented behavior, and user-owned setup.
- Use bounded queries and report the time range and source scope.
- Link to the relevant Ravan page or external operator tool.
- Do not claim that Kafka UI, Grafana, or Prometheus were changed by Ravan.
